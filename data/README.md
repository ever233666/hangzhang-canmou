# 知识库数据说明

这里的两份 JSON 是**演示数据**，用于打通产品链路和录制 Demo，不能直接作为合规或申报依据。

- `rules.json`：合规规则卡。每条带 `source_url` 与 `verified` 字段。当前全部为 `false`，意味着条款要点需要人工逐条核对到官方原文。
- `policies.json`：政策库。金额、比例、截止日期一律写「以当年通知为准」，没有编造具体数字。

**提交作品前的必做动作**：把与你们案例品类相关的 8—12 条规则，逐条打开 `source_url` 核对，核对通过的把 `verified` 改成 `true`。界面上未核对的条目会显示「待核对」角标——这本身就是答辩时的一个加分点：我们知道自己哪里不确定。
